# Boundless

Learn by doing project with an ESP-32 and add-ons

## Requirements (WIP)
- ESP-IDF v6.0.1
- An ESP32 board

## Instructions (WIP)
- Adjust the sdkconfig.defaults according to the board being used (if unsure delete to enable ESP-IDF defaults)
- Connect ESP32 board
- Open ESP-IDF terminal on the root folder of the repository
- Run: ``` idf.py build flash monitor ```
